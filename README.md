# Team Personality Map

MVP Next.js app for Big Five/IPIP-style reflection and team communication insights.

## Run

```bash
npm install
npm run dev
```

## Notes
- Reflection and communication tool only; not diagnosis, therapy, or hiring assessment.
- Uses public-domain IPIP-style item format in `lib/questionnaire/items.ts`.
- LocalStorage persistence with clean service abstraction in `lib/services`.
